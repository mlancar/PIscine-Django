1. General functionning of Django's template engine.

the Django's template engine is used to dynamically generate HTML pages by inserting Pythom variables and by using specific syntax in .html files The engine works as follow :

  1. A view (views.py) send a context (variables) to a HTML template
  2. The template contains tags {% ... %} (logic) and {{ ... }} (display of variables).
  3. Django interprete the template and generate a final HTML page.

2. Blocks {% block ... %}

Blocks are used to define modifiables zone in a parent's template. It is the base of the C'est la basis of the inheritance system of templates.

Exemple 

    <html>
        <head>
            <title>{% block title %}Default title{% endblock %}</title>
        </head>
        <body>
            {% block content %}Default content{% endblock %}
        </body>
    </html>
            

    {% extends "base.html" %}

    {% block title %}Home page{% endblock %}

    {% block content %}
        <p>welcome on the website</p>
    {% endblock %}
Results : page.html inherite base.html and replace the title blocks and content.

3. Loops {% for ... in ... %}

Allow to browse a list snet in the context and generate dynamically HTML. 

    <ul>
        {% for fruit in fruits %}
        <li>{{ fruit }}</li>
        {% endfor %}
    </ul>
        

    def my_vue(request):
        return render(request, "fruits.html", {"fruits": ["Apples", "Bananas", "Cherries"]})
Will display a list <li> with every fruits.

4. {Structures % if ... %}

Permettent de faire des conditions dans le template. 

    {% if user.is_authenticated %}
        <p>Hello {{ user.username }} !</p>
    {% else %}
        <p>Welcome, visitor.</p>
    {% endif %}
You can also use {% elif %} for several cases.

5. Display of variables : {{ variable }}

All the data of the context send by the view can be displayed with : 

        <p>Hello{{name }} !</p>
If in the view you have : 

    def my_vue(request):
        return render(request, "index.html", {"name": "Marine"})

The template will display : Hello Marine !
