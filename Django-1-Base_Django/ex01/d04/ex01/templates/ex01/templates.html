Bienvenue sur la page Django

1. Fonctionnement général du moteur de templates Django

Le moteur de templates de Django sert à générer dynamiquement des pages HTML en insérant des variables Python et en utilisant une syntaxe spéciale dans des fichiers .html. Le moteur fonctionne ainsi :

  1. Une vue (views.py) envoie un contexte (des variables) à un template HTML.
  2. Le template contient des balises {% ... %} (logique) et {{ ... }} (affichage de variables).
  3. Django interprète le template et génère une page HTML finale.

2. Les blocs {% block ... %}

Les blocs servent à définir des zones modifiables dans un template parent. C'est la base du système d'héritage de templates.

Exemple 

    <html>
        <head>
            <title>{% block title %}Titre par défaut{% endblock %}</title>
        </head>
        <body>
            {% block content %}Contenu par défaut{% endblock %}
        </body>
    </html>
            

    {% extends "base.html" %}

    {% block title %}Page d'accueil{% endblock %}

    {% block content %}
        <p>Bienvenue sur le site !</p>
    {% endblock %}
Résultat : page.html hérite de base.html et remplace les blocs title et content.

3. Les boucles {% for ... in ... %}

Permettent de parcourir une liste envoyée dans le contexte et de générer du HTML dynamiquement. 

    <ul>
        {% for fruit in fruits %}
        <li>{{ fruit }}</li>
        {% endfor %}
    </ul>
        

    def ma_vue(request):
        return render(request, "fruits.html", {"fruits": ["Pommes", "Bananes", "Cerises"]})
Affichera une liste <li> avec chaque fruit.

4. {Les structures % if ... %}

Permettent de faire des conditions dans le template. 

    {% if user.is_authenticated %}
        <p>Bonjour {{ user.username }} !</p>
    {% else %}
        <p>Bienvenue, visiteur.</p>
    {% endif %}
Tu peux aussi utiliser {% elif %} pour plusieurs cas.

5. Affichage des variables : {{ variable }}

Toutes les données du contexte envoyées par la vue peuvent être affichées avec : 

        <p>Bonjour{{nom }} !</p>
Si dans la vue tu as : 

    def ma_vue(request):
        return render(request, "index.html", {"nom": "Marine"})

Le template affichera : Bonjour Marine !
Tu peux aussi accéder aux attributs et méthodes :


    <p>{{ utilisateur.nom }}</p>
        <p>{{ objet.prix|floatformat:2 }}</p>
