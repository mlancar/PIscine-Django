Processus d'affichage d'une page statique

L'utilisateur entre une URL dans son navigateur (ex. http://localhost:8000/apropos) → Le navigateur envoie une requête HTTP GET au serveur Django.

  • l'authentification utilisateur,
  • l'administration du site,
  • la sécurité (CSRF, XSS, etc.),
  • et bien plus encore, sans avoir à tout coder soi-même.

    • Django analyse l'URL (routing)

    La requête est reçue par Django, qui va :

    1. Consulter le fichier urls.py du projet (ou d'une app),
    2. Rechercher une correspondance avec l'URL demandée,
    3. Si une correspondance est trouvée, il exécute la fonction (ou classe) vue associée.
    Exemple

    # urls.py
    from django.urls import path
    from . import views
    urlpatterns = [
    path("apropos/", views.apropos, name="apropos"),
    ]

    Appel de la vue (views.py)

    La vue est une fonction Python qui prépare la réponse à envoyer.

    # views.py
    from django.shortcuts import render
    def apropos(request):
    return render(request, "apropos.html")

    Ici, la vue dit à Django :
    • de charger le template apropos.html,
    • et de le rendre (render) en HTML à partir d'un contexte (ici vide).

    Django charge le template HTML

    Django cherche le fichier apropos.html dans les répertoires définis dans TEMPLATES (settings.py). Il lit le contenu HTML du template et l'interprète :

      {% comment %}
    • '"Si le fichier contient des balises Django ({{ }}, {% %}), elles sont évaluées."'
      • {% endcomment %}
    • Ici, comme c'est une page statique, il n'y a généralement pas de logique dynamique.

    Django construit la réponse HTTP

    Une fois le HTML final généré, Django :
    • Le place dans un objet HttpResponse
    • Y ajoute des en-têtes HTTP (ex: Content-Type: text/html)
    • L'envoie au navigateur du client

    . Le navigateur affiche la page

    Le navigateur reçoit la réponse HTTP contenant le code HTML généré. Il interprète ce code et affiche la page à l’utilisateu.

    Résumé schématique

    [ Navigateur ] --GET--> [ urls.py ] --> [ views.py ] --> [ Template HTML ] ^ | |<---------------------- HttpResponse (HTML) --------------|
