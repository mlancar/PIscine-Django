Display process of a static page

The user enter a URL in his browser (ex. http://localhost:8000/apropos)
→ The browser send a HTTP request GET to the Django server.

  • User authentuification,
  • l'administration du site,
  • Security (CSRF, XSS, etc.),
  • and way more, without having to code it yourself.

    • Django analyse URL (routing)

    The request is received by Django, who will::

    1. Consult urls.py file of the project (or an app),
    2. Research a match with the requested URL,
    3. If a match is found, it execute the associated view function (or class) associeted view.Si une correspondance est trouvée, il exécute la fonction (ou classe).
    Exemple

    # urls.py
    from django.urls import path
    from . import views

    urlpatterns = [
    path("apropos/", views.apropos, name="apropos"),
    ]

    Call the view (views.py)

    The view is a Python function that prepares the response to be sent.the La vue est une fonction Python qui prépare la réponse à envoyer.

    # views.py
    from django.shortcuts import render

    def apropos(request):
    return render(request, "apropos.html")

    Here, the view say to Django :
    • to load the template apropos.html,
    • and to render it in HTML from the context (empty here).

    Django load the HTML template

    Django search the apropos.html file in the directory define in TEMPLATES (settings.py). It reads the HTML content of the template and interprets it

      {% comment %}
    • '"If the file contains Django tags ({{ }}, {% %}), they're evaluated."'
      • {% endcomment %}
    • Here, since it is a static page, so they are usually no dynamic logic.

    Django build the HTTP response

    Once the final HTML generated Django:
    • Put it in a HttpResponse object
    • add headers to it (ex: Content-Type: text/html)
    • Send it to the client's browser

    The browser display the page

    HTTP

    the browser receives the HTTP response containing the HTML generated code. IT interpretes the code and display the page to the user.

    Schematic summary

    [ Browser ] --GET--> [ urls.py ] --> [ views.py ] --> [ Template HTML ]
    ^ | |<---------------------- HttpResponse (HTML) --------------|
