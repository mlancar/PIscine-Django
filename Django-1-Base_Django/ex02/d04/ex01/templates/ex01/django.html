Qu'est-ce que Django ?

Django est un framework web open source écrit en Python. Il permet de créer des sites web robustes, rapides et sécurisés en suivant le principe "Don't Repeat Yourself" (DRY). Il est basé sur le modèle MTV (Model-Template-View), très proche du MVC. Django fournit tout ce qu’il faut pour gérer :

  • les bases de données (ORM),
  • les templates HTML,
  • l’authentification utilisateur,
  • l’administration du site,
  • la sécurité (CSRF, XSS, etc.),
  • et bien plus encore, sans avoir à tout coder soi-même.

Historique de Django

  • 2003 : Début du développement par Adrian Holovaty et Simon Willison, deux développeurs de journalisme web du Lawrence Journal-World (un journal américain).
  • 2005 : Le framework est publié en open source sous licence BSD.
  • Il est nommé "Django" en hommage à Django Reinhardt, un célèbre guitariste de jazz manouche.
  • 2008 : Sortie de la version 1.0 stable.
  • Depuis, Django a évolué avec des versions régulières (tous les 8 mois environ) et une communauté très active.
  • Dernières versions : Django 4.x et 5.x (selon le moment où tu lis cela).

Pourquoi Django est si populaire ?

  • Très bien documenté
  • Sécurisé par défaut
  • Admin intégré très puissant
  • Utilisé par des sites majeurs : Instagram, Pinterest, Mozilla, Disqus, The Washington Post…
