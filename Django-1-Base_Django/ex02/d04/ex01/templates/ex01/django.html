What is Django ?

Django is a framework web open source written en Python. It allows to create strong website, fast and secure by follwing the "Don't Repeat Yourself" (DRY) principles. It is based on the MTV model (Model-Template-View), very close to the MVC, Django provides everythin gyou need to:

  • Databasess (ORM),
  • HTML templates,
  • User authentuification,
  • administration of the website,
  • Security (CSRF, XSS, etc.),
  • et bien plus encore, sans avoir à tout coder soi-même.

Django's historic

  • 2003 : beginning of the devlopment by Adrian Holovaty and Simon Willison, two devlopper from journalisme web of Lawrence Journal-World.
  • 2005 : The framework is published in under licence BSD.
  • It is named "Django" in tribute to Django Reinhardt, a famous jazz manouche guitarist.
  • 2008 : Release of the stable version 1.0 .
  • Since, Django has evolve with regular releases (every 8 months) and a very active community.
  • Last releases : Django 4.x et 5.x

Why is Django so popular ?

  • Well documented
  • Secured by default
  • Admin integrated very powerful
  • Use by major websites : Instagram, Pinterest, Mozilla, Disqus, The Washington Post...
